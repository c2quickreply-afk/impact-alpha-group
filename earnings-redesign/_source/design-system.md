# Impact Earnings: design system

Plain HTML, CSS and JS. Multi-page, no npm, no build step. Two shared files carry the whole system:

- `assets/site.css`: tokens at the top, then every component
- `assets/site.js`: loader, nav, reveals, counters and visuals (no dependencies)
- `assets/gate.js`: a tiny blocking `<head>` script that adds `.js` and skips the loader on repeat pages

The pages (`index.html`, `about.html`, `community.html`, `contact.html`, `404.html`) are static HTML. They share a nav and footer, which `_source/build_pages.py` generates from `_source/partials.py`. Edit the HTML directly, or edit those two files and run `python -I _source/build_pages.py` to rewrite all pages at once.

No inline `<script>` blocks, so the existing strict CSP in the repo's root `vercel.json` (`script-src 'self'`) keeps working with no hashes to update. Fonts come from Google Fonts, which that CSP already allows.

## Copy rule

Every sentence outside the illustrative visuals is the client's own wording, copied word for word from the original site (repo root `earnings.html`, or `alpha.html` for Alpha). That includes nav and button labels. No new headings, taglines or quotes. Only the visuals (the call window, custody flow, checklist, security ring, mail card) carry their own short labels, and none of them puts words in Francene's mouth. `python -I _source/copycheck.py` checks this and lists any line that isn't in the original.

## Loader

The original markup, CSS and timing are ported verbatim (see `_source/loader/`). The CSS is scoped under `.loader` with the original colour/font variables, so the new tokens never touch it.

- It dismisses at `window.load + 2650ms` (100ms with reduced motion), exactly like the original.
- It shows only on the first page of a visit: `sessionStorage.ie_loader_seen` is set, and `gate.js` adds `.no-loader` before paint on later pages.
- It always lifts: there's a JS fallback at 6s and a CSS-only failsafe animation at 7s in case JS never runs.
- Hand-off: the original 0.8s opacity fade reveals the light hero while the hero copy and chart animate in.

## Applying this to a sister site (Impact Alpha)

1. `_source/partials.py`: change `SITE` (name, loader word, links), `NAV_ITEMS` and the footer copy. For the loader, change only the `loader_word`.
2. Logo: the emblem is shared. Change the wordmark text in `nav()`/`footer()` and the `aria-label`s.
3. Accent tint (optional): override `--emerald` / `--emerald-soft` (and `--gold-ink` if wanted) in `:root`. Keep `--forest-*` as the anchor. Never use purple.
4. Copy: replace page bodies in `_source/build_pages.py` with Alpha's original wording (see the copy rule above), run it, then run `copycheck.py` pointed at `alpha.html`. Hero visual: keep the `.call` frame and swap the slide content for something authentic to Alpha (for example, a partnership pipeline), clearly labeled as illustrative.
5. Keep `<meta name="robots" content="noindex, nofollow">` and the `X-Robots-Tag` header until launch.

## Local preview and QA

- `node _source/serve.mjs 3000` serves the site with clean URLs, like Vercel's `cleanUrls`.
- `python -I _source/copycheck.py` confirms all copy is the original's.
- `python -I _source/qa.py` screenshots every page at 375/768/1280/1920/2560 to `_source/qa/` and writes `_source/qa/report.txt`.
